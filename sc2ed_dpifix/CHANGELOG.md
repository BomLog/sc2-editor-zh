# 更新记录

## 1.5.0 - 2026-09-05

- **框架化资源包架构**：`packages/hook`（DLL + 翻译表 → `deploy/`）和 `packages/editor`（界面字符串 → 编辑器目录），每个包附 `package.json` 清单；editable 文件首次释放后归用户所有，未被外部修改时才随包静默更新，被修改过则永不覆盖。
- **清晰度修复与汉化独立开关**：三种有效启动组合——同时启用、仅汉化、仅清晰度修复；两者都关闭时拒绝启动并提示。
- **全表精校完成**：五轮术语精校（`tools/polish_terms.py` + `tools/apply_polish.py`），修正 ~24,458 条值——Hunter 系列误译、单位术语统一、函数词误译、War3 彩蛋污染；英文残留 31,982 (16.6%) → 11,925 (6.2%)，剩余均为设计保留的技术标识。精校管线幂等可重跑。
- **启动器署名栏**：界面底部醒目展示原汉化贡献者（头目 · hgzerg · OB）和工具开发者（BoomFirst），原汉化者行带青色辉光强调。
- 启动器进程创建根据实际需要决定是否挂起：仅 DPI 修复或汉化注入时挂起，无需修补时正常创建。
- 单文件 EXE 打包（PyInstaller onefile），资源包内嵌于 `_MEIPASS`，约 59 MB。

## 1.4.0 - 2026-09-03

- **IAT Hook 替代调用点 Hook**：Hook 主模块 IAT 中的 `SendMessageW`（slot RVA `0x32BC328`），拦截所有 `TVM_INSERTITEMW` 和 `TVM_SETITEMW`（mask 含 TVIF_TEXT）消息。解决了 94% 树项以空文本插入、真实文本由 vtable 分发的 `TVM_SETITEMW` 晚设置的根因问题。
- 树节点翻译覆盖率从不足 21% 提升至接近 100%（技术标识除外）。

## 1.3.4 - 2026-09-01

- 修正通用树 Hook 的参数类型：改在 `TVM_INSERTITEMW` 调用点替换已转换的 UTF-16 标签，实际覆盖效果等已有英文名称。
- 新调用点同时使用 IDA 参数布局与 CE 运行时机器码校验，签名不一致时拒绝安装。

## 1.3.3 - 2026-09-01

- 完整变体别名优先于括号和层级回退，避免效果等对象误命中基础名称。
- 启动器必须确认缺省名称 Hook 与通用树节点 Hook 均已安装，并优先报告任一 Hook 的拒绝原因。
