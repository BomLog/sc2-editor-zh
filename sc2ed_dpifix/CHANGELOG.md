# 更新记录

## 1.2.0 - 2026-08-27

- 增加“暂时卸载/恢复汉化”按钮，便于在编辑器打包前移走 Hook 和外置文本。
- 暂存文件按原目录保存并记录 SHA-256；恢复前验证完整性，目标冲突会先备份。
- 编辑器运行期间拒绝暂存或恢复，避免移动正在使用的文件。
- 内置汉化资源改为按内容去重的 LZMA 压缩包，释放时仍执行原有校验。

## 1.1.0 - 2026-08-27

- 将官方依赖汉化改为可选功能。
- 对外置汉化文件进行稳定校验；缺失时释放，不一致时备份后替换。
- DLL 校验 PE 标志、必要导出和当前 Hook 版本；损坏、第三方或旧版 DLL 会备份后替换。
- 文本与 TSV 资源使用严格 SHA-256 校验。
- 修正字段目录资源来源，恢复完整的 21,439 键字段表。
- 补齐 8 个仍会直接显示英文的字段；技术标识与格式 TOKEN 保持原文。
- 增加版本显示和原汉化者署名。
- 将源码、构建脚本、测试和版本文件纳入 Git 管理。
